# OutRun function list comparison: iOS vs HarmonyOS

- **Source:** OutRun for iOS 1.3 (upstream tag `v1.3`), 238 functions.
- **Target:** OutRun for HarmonyOS (`etspworks/OutRun-HarmonyOS` main, release 2026-10-07), 181 functions.
- Function lists: `Function_List_OutRun-1.3.xlsx` (iOS) and `Function_List_OutRun-HMOS-20261007-release.xlsx` (HarmonyOS).
- ✅ = the function is in that app's function list, ❌ = it is not.
- The function text comes from the iOS list, or from the HarmonyOS list when iOS lacks it.
- A HarmonyOS function that the iOS list splits into several rows is ticked on each of them.
- 248 rows: 169 in both, 69 iOS only, 10 HarmonyOS only.
- A note with #N points to the row whose function gives the same result.
- Many ❌ rows in the HarmonyOS column are list granularity, not missing features; the note says which.
- Level 1 Module is a screen of the app, or Global for launch and app-wide behaviour; Level 2 Module,
  Level 3 Module and Level 4 Module are the elements tapped from it, one level per tap. A row ends at its
  own level, so the deeper columns stay empty. An element that opens further elements (a page, alert,
  sheet or picker) has its own row first, with its name repeated in the next column. A button of an alert
  that no tap opens carries the alert's name in brackets, for example Okay (sync error alert).
- New Workout, Workout Detail and Edit Workout are Level 1 Modules of their own; the row that opens
  them stays in the module they are opened from.
- A module, element or page is one merged cell over all the rows of its group. A markdown table cannot
  merge cells, so the table below is written in HTML.
- The same tables are in the workbook [FUNCTION_LIST_COMPARISON.xlsx](FUNCTION_LIST_COMPARISON.xlsx),
  with each group as merged cells.
